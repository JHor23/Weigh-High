# Weigh High

Weigh High is a lightweight digital scale application designed for quick, high-precision calculations, unit conversions, and advanced hardware telemetry.

Whether you're performing micro-measurements, switching sensing modes, or logging historical data, Weigh High optimizes performance, precision, and sensor calibration for an elevated mobile measurement experience.

---

## ✨ Key Features

* ⚖️ **Multi-Mode Hardware Sensing:** Switch seamlessly between **Touch**, **Barometer**, and **Fusion** weighing methods to leverage your device's native hardware sensors.
* 🔄 **Live Unit Converter:** Instantly convert values across multiple measurement units (including grams [g], ounces [oz], carats [ct], grains [gr], and milligrams [mg]) right from the primary interface.
* 🛠️ **Calibration & Diagnostics:** Fine-tune your scale using standard coins or custom masses alongside live sensor telemetry tracking touch pressure, area, and barometer data.
* 📊 **Weight History & Visuals:** Track past measurements using the built-in Weight History Log and explore an animated balance scale via the Visual Weight Representation tool.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Build and run the application via your preferred Android/web development environment.
3. Launch the app, select your preferred hardware sensing mode (Touch, Barometer, or Fusion) from the options menu.
4. Calibrate the scale using standard reference weights or coins if necessary.
5. Place your item or container on the screen, use **TARE** or **HOLD** as needed, and view your precise measurements!
